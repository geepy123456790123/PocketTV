Setup after checkout

1

Create your subscription

Stripe starts the 7-day trial and returns you to the PocketTV setup page.

2

Get one code

Your account gets a short activation code like PK7X2Q9A.

3

Enter it in PocketTV

Open PocketTV, choose Premium, and enter the code. The app receives the proxy URLs automatically.

Built for the proxy

The app never sees upstream feed addresses. PocketTV sends your activation code to the backend and receives public proxy URLs that can be rotated, revoked, or regenerated.

Cancel anytime

If a subscription is canceled or payment fails, the backend disables that customer code and token. The proxy stops serving playlist, guide, stream, and logo requests.
